# Open Source Foundation

**Useful software, open to everyone.**

Open Source Foundation creates open-source tools that anyone can access, run, inspect, and improve. We want people to have more control over the software they use and the data they share. Open development also gives ideas room to grow across different fields of technology.

This organization is just getting started. Our first project is [WhichLLMs](https://github.com/Open-Source-Foundation/whichllms); more projects may follow as they become ready to use.

## Our first project: WhichLLMs

[WhichLLMs](https://github.com/Open-Source-Foundation/whichllms) helps you compare language models on your own prompts. It uses an LLM judge to evaluate answers against clear criteria, then lets you inspect the responses, explanations, latency, and reported costs yourself.

You can clone the repository and run the interface locally. Bring your own OpenRouter API key, choose from the text models available to your account, add prompts manually or from a CSV file, and export the results. You can evaluate saved answers again with a different judge without paying to generate them a second time.

WhichLLMs keeps its draft and results in your browser. Model requests still go through OpenRouter and its providers, so prompts and generated answers are shared with the services you choose. The [project README](https://github.com/Open-Source-Foundation/whichllms#readme) explains setup, costs, and data handling in detail.

## Contributing

We welcome bug reports, feature ideas, documentation improvements, and code contributions across our projects.

1. Open an issue in the relevant repository to report a bug or propose a feature. Check existing issues first and include enough context for others to understand the problem.
2. To contribute code or documentation, fork the repository, make a focused change, and open a pull request against its default branch. Follow that project's contributing guide and run its required checks before submitting.
3. Pull requests are reviewed by members of the organization's [reviewers team](https://github.com/orgs/Open-Source-Foundation/teams/reviewers) before they are merged. Contributors cannot push changes directly to protected default branches. Organization maintainers may use explicitly granted bypass permissions for their own changes.

For WhichLLMs, read the [contributing guide](https://github.com/Open-Source-Foundation/whichllms/blob/main/CONTRIBUTING.md) before opening a pull request.

Open source works best when people can understand the tools they depend on and help shape what comes next.
